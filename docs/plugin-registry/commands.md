Registers and handles slash commands in chat sessions (e.g., `/status`, `/compact`, `/model`).

## Package Info

| Field | Value |
|-------|-------|
| Package | `@elizaos/plugin-commands` |
| Feature flag | `features.commands` |

## Configuration

```json
{
  "features": {
    "commands": true
  }
}
```
