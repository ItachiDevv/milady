Provides structured form handling capabilities, allowing agents to collect and validate user input through multi-step form flows.

## Package Info

| Field | Value |
|-------|-------|
| Package | `@elizaos/plugin-form` |
| Feature flag | `features.form` |
| Core plugin | Included by default in the core plugin set |

## Configuration

```json
{
  "features": {
    "form": true
  }
}
```
