The x402 plugin implements the HTTP 402 Payment Required protocol, enabling Milady agents to handle micropayments for premium services and content access.

**Package:** `@elizaos/plugin-x402`

## Installation

```bash
milady plugins install x402
```

## Enable via Features

```json
{
  "features": {
    "x402": true
  }
}
```

## Configuration

| Environment Variable | Required | Description |
|---------------------|----------|-------------|
| `X402_PRIVATE_KEY` | Yes | Private key for signing payment transactions (sensitive) |
| `X402_AGENT_URL` | No | Agent endpoint URL |
| `X402_NETWORK` | No | Network name (e.g., `mainnet`, `testnet`) |
| `X402_PAY_TO` | No | Payment recipient address |
| `X402_FACILITATOR_URL` | No | Facilitator service URL |
| `X402_MAX_PAYMENT_USD` | No | Maximum single payment in USD |
| `X402_MAX_TOTAL_USD` | No | Maximum total spend in USD |
| `X402_ENABLED` | No | Enable or disable the plugin |
| `X402_DB_PATH` | No | Database file path for payment records |

### milady.json Example

```json
{
  "features": {
    "x402": true
  },
  "env": {
    "X402_PRIVATE_KEY": "0x...",
    "X402_NETWORK": "mainnet",
    "X402_PAY_TO": "0x...",
    "X402_MAX_PAYMENT_USD": "1.00",
    "X402_MAX_TOTAL_USD": "100.00"
  }
}
```

## Features

- HTTP 402-based micropayment handling
- Pay-per-request agent service monetization
- Integrates with blockchain wallet for payment processing
- Configurable payment limits (per-transaction and total)
- Facilitator service support for payment routing
