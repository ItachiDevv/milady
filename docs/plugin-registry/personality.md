Manages agent personality traits, style modifiers, and behavioral presets. Allows dynamic personality adjustments during runtime.

## Package Info

| Field | Value |
|-------|-------|
| Package | `@elizaos/plugin-personality` |
| Feature flag | `features.personality` |
| Core plugin | Included by default in the core plugin set |

## Configuration

```json
{
  "features": {
    "personality": true
  }
}
```
