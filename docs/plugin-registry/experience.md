Tracks agent interaction experiences over time, enabling learning from past conversations and building contextual awareness across sessions.

## Package Info

| Field | Value |
|-------|-------|
| Package | `@elizaos/plugin-experience` |
| Feature flag | `features.experience` |
| Core plugin | Included by default in the core plugin set |

## Configuration

```json
{
  "features": {
    "experience": true
  }
}
```
